# دستیار هوشمند تحلیل آزمایش خون

وب‌اپلیکیشن فارسی Streamlit برای دریافت تصویر/PDF آزمایش، استخراج پارامترها، مقایسه با محدوده مرجع خود برگه، توضیح محتاطانه و تولید PDF.

> هشدار: این پروژه نمونه آموزشی است؛ ابزار تشخیص یا تجویز نیست. نتایج باید توسط پزشک و با توجه به سن، جنس، علائم، سابقه پزشکی، داروها و محدوده مرجع آزمایشگاه بررسی شوند.

## اجرا
1. Python 3.10+ نصب کنید.
2. محیط مجازی بسازید و وابستگی‌ها را نصب کنید:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. فایل .env.example را به .env کپی کنید و OPENAI_API_KEY را تنظیم کنید.
4. اجرا: `streamlit run app.py`

## تنظیمات
- OPENAI_API_KEY: کلید API؛ فقط در Secrets میزبان نگه‌داری شود.
- OPENAI_MODEL: پیش‌فرض gpt-4.1-mini
- MAX_UPLOAD_MB: سقف حجم فایل، پیش‌فرض 12

## فونت PDF فارسی
یک فونت TTF دارای حروف فارسی (مانند Vazirmatn یا Noto Naskh Arabic) را در assets/fonts/ قرار دهید. بدون فونت مناسب، شکل‌دهی فارسی در PDF ممکن است ناقص باشد.

## حریم خصوصی
- فایل در این نمونه به‌صورت پایدار ذخیره نمی‌شود.
- برای تحلیل، تصویر به OpenAI API ارسال می‌شود؛ پیش از استفاده واقعی، رضایت آگاهانه و الزامات قانونی را رعایت کنید.
- اطلاعات هویتی را پیش از بارگذاری حذف کنید.
- خروجی OCR/مدل ممکن است خطا داشته باشد؛ همه مقادیر را با اصل برگه تطبیق دهید.
- اگر محدوده مرجع درج نشده باشد، برنامه از حدس‌زدن آن خودداری می‌کند.

## ساختار
- app.py: رابط کاربری و چهار مرحله تحلیل
- requirements.txt: وابستگی‌ها
- .env.example: نمونه تنظیمات بدون کلید محرمانه


## اجرای آنلاین با Streamlit Community Cloud
1. وارد Streamlit Community Cloud شوید و حساب GitHub را متصل کنید.
2. گزینه New app را انتخاب کنید و این مخزن و فایل اصلی app.py را مشخص کنید.
3. در App settings → Secrets مقدار زیر را ثبت کنید:
   ```toml
   OPENAI_API_KEY = "کلید-واقعی-شما"
   OPENAI_MODEL = "gpt-4.1-mini"
   MAX_UPLOAD_MB = "12"
   ```
4. Deploy را بزنید. کلید API را در کد یا فایل‌های مخزن قرار ندهید.

## وضعیت اعتبارسنجی
یک GitHub Actions workflow برای بررسی نحوی app.py با Python 3.11 در هر push تعریف شده است. اجرای واقعی برنامه نیازمند نصب وابستگی‌ها و تنظیم کلید API معتبر است.
